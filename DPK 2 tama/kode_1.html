Browser

HTML
HTML merupakan singkatan dari Hyper Text Markup Language, berfungsi untuk memperindah file teks biasa yang akan ditampilkan pada browser dengan menambahkan tag-tag pada file teks biasa tersebut.
PHP
Salah satu bahasa pemrograman server-side yang digunakan untuk membangun website menjadi dinamis.
Notepad
Salah satu editor teks yang digunakan untuk menulis coding dalam membuat halaman web.
